# 五天执行计划：周期信号题与直接衍生模块

> 时间：连续 5 天。目标：完成周期信号题基础要求，并沉淀可复用的 ADC+DMA、时间捕获、PGA 控制、测量算法、显示和校准模块。扩展要求不做。DDS 只完成 V0.1 原理图/接口和模块驱动验证，不挤占基础题验收时间。

## 总目标

第五天结束时必须具备：

- 识别正弦波、三角波、矩形波。
- 测量 100 Hz~10 kHz 频率，误差 <=1%。
- 测量 1~5 Vpp，误差目标 <=1%；若硬件系统误差暂未压到 1%，必须有完整校准数据和明确剩余误差。
- 测量矩形波 20%~80% 占空比，误差 <=2%。
- ILI9341 显示类型、频率、Vpp、占空比和错误状态。
- 连续运行 1 h、重复上电 20 次无异常。
- 形成统一 M0G3507 整机工程、接口表、测试表和回退固件。
- 完成 AD9833 DDS V0.1 原理图、BOM、接口定义；只有基础题通过后才允许投板。

## 固定技术路线

```text
BNC -> 已验证前端 -> BUFFER1
                     +-> PGA 固定 x2 -> BUFFER2 -> ADC+DMA
                     +-> TLV3501 -> TIMG12 -> f / D

M0G3507 -> 测量算法 -> ILI9341 文本显示
```

- PGA 默认固定 x2，上电设置一次，不做自动量程。
- 若 5 Vpp 输入在 ADC 前削顶，整套测试统一改固定 x1。
- ADC 先用 200 kSPS、2048 点；不稳定时退到 100 kSPS、1024 点。
- TIMG12 32 位双边沿捕获，固定平均 16 周期。
- 不用 RTOS，不做 FFT，不做扩展波形，不做外置 ADC。
- LCD 只刷新数值区，不画实时波形。

## Day 3：三种波形识别与分波形 Vpp

### 上午：算法

- [ ] ADC 数据减去平均值得到交流分量。
- [ ] 计算 RMS、粗略 Vpp、平台样本比例、导数分布。
- [ ] 先判断矩形：明显上下平台 + 少量快速边沿。
- [ ] 非矩形按 `RMS/Vpp_rough` 区分正弦和三角。
- [ ] 连续两帧得到相同类型后才更新显示，减少跳变。
- [ ] 分波形计算 Vpp：
  - 正弦：`2*sqrt(2)*RMS_ac`。
  - 三角：`2*sqrt(3)*RMS_ac`。
  - 矩形：上下平台中位数之差。

### 下午：离线样本

- [ ] 保存三种波形各一帧 ADC 原始数据到 UART/文本。
- [ ] 在表格中计算 RMS、粗 Vpp、比值和分类结果。
- [ ] 调整阈值，不在 MCU 上反复盲改。

### 晚上：识别和幅值初测

测试组合：

- 三种波形。
- 100 Hz、1 kHz、10 kHz。
- 1 Vpp、3 Vpp、5 Vpp。
- 矩形先固定 50% 占空比。

先做 9 个代表点：每种波形在 1 kHz 下测 1/3/5 V，再测每种波形 100 Hz 和 10 kHz 的 3 V点。

### 当日交付

- [ ] 三种波形各连续识别 30 次，无明显乱跳。
- [ ] 所有 Vpp 点先进入 3% 以内。
- [ ] 记录每种波形的系统偏差方向。
- [ ] 保存 `day3_classify_vpp_raw` 固件和原始样本。

### 不通过时

- 类型错：先看原始采样是否完整覆盖一个周期，再调分类阈值。
- Vpp 错：先确认前端实际增益和信号源负载设置，再改算法。
- 不要同时改硬件增益、采样率和算法阈值。
