### EDC Universal Measurement Front End V1.0（电赛通用测量前端）
| 项目   | 指标                | 设计理由                |
| ---- | ----------------- | ------------------- |
| 输入接口 | BNC               | 仪器标准接口，便于接信号源/示波器   |
| 输入阻抗 | **50Ω / 1MΩ 可切换** | 满足本题50Ω要求，同时兼容后续测量题 |
| 输入频率 | DC～5MHz（目标）       | 赛题2MHz，留2倍以上裕量      |
| 输入幅度 | ±10V（目标）          | 大多数电赛输入不会超过这个范围     |
| 最大保护 | ±20V瞬态不损坏         | 防误接、调试安全            |
| 输入耦合 | DC（预留AC耦合焊盘）      | 本题测脉冲必须DC耦合         |
| 输入带宽 | ≥20MHz（目标）        | 保证2MHz方波边沿不过度失真     |
| 输入噪声 | 尽量低               | 提高测量稳定性             |

#### 器件
| 模块      | 推荐器件                          | 数量 | 说明                 |
| ------- | ----------------------------- | -- | ------------------ |
| 输入接口    | BNC-KWE                       | 1  | PCB安装BNC座          |
| TVS保护   | PESD12VL1BA 或 PESD15VS1UL     | 1  | 低电容ESD保护，正常10V不动作  |
| 输入匹配    | 49.9Ω ±0.1% 25ppm             | 1  | **输入阻抗50Ω**，推荐薄膜电阻 |
| 固定衰减    | 70kΩ ±0.1%、30kΩ ±0.1%         | 各1 | 固定0.3衰减（最终可根据仿真微调） |
| Buffer① | **OPA356AIDBVR**              | 1  | 高速缓冲，隔离衰减网络        |
| 程控放大运放  | **OPA356AIDBVR**              | 1  | 统一器件，方便调试          |
| 模拟开关    | **ADG704BRMZ**                | 1  | 四路SPST，用于切换反馈电阻    |
| 增益电阻    | 10k、20k、49.9k、100k、200k（0.1%） | 若干 | 实现×1/×2/×5/×10/×20 |
| Buffer② | **OPA356AIDBVR**              | 1  | 驱动ADC和比较器          |
| 高速比较器   | **TLV3501AIDBVR**             | 1  | 4.5ns传播延迟          |
| ADC RC  | 22Ω + 100pF C0G               | 各1 | ADC抗混叠及驱动稳定        |
| 去耦电容    | 100nF + 1µF（每颗IC）             | 若干 | 紧贴电源引脚放置           |
